# Known issues

User-facing. Ships in the zip once there is one. Each entry: what a player sees, the
workaround, and the ticket or milestone that closes it. Faults found by a session and not
fixed get an entry here AND a ticket; the PR names both.

## Nothing released yet

There is no build to install. When the first tester build exists, this file lists what is
wrong with it.

## Entry format

```
### <What the player sees>
- Since: <version>
- Workaround: <what to do>
- Closes with: VR-<n> / <milestone>
```
